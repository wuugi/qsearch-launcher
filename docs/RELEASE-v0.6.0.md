Personal and Work tabs in the app drawer.

### New

- If your phone has a work profile, the app drawer now shows **Personal** and **Work** tabs. Work apps are in the Work tab, and everything else is in Personal. Each tab has its own "Frequently used" row and letter bar.
- Dual apps (cloned apps) are not work apps, so they stay in Personal.
- Phones without a work profile see one list, as before.
- The tabs need Android 15 or later. On older Android versions the drawer shows one list, as before.

### Install

Download `QSearchLauncher-0.6.0.apk` below and install it over 0.5.9. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
