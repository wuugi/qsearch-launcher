A short guide now shows the basics the first time you open the launcher, and phones without a hardware keyboard can reach every setting.

### First-run guide

- The first time you open the home screen, a few cards show how to set the launcher as your home app, open the search bar, get answers by typing (apps, calculations, currency) and use favorites and the app drawer.
- It shows once. Skip it at any time with "Skip guide", or open it again from Settings → Help → "Replay the guide".
- It works with the keyboard (Enter for next, Esc to close) and with touch.
- If the guide fails to open, home and search still work.
- The guide only mentions features that are in this build, and it adds no new permissions.

### Phones without a hardware keyboard

- Long-pressing the home screen and choosing Settings now opens the normal settings screen when no hardware keyboard is attached. Before, it always opened the search shortcut step, so these phones could not reach the rest of the settings.
- The "Choose a search bar shortcut" button on the home screen is hidden when no hardware keyboard is attached. Open search from the search bar in the app drawer instead.

### Fixes

- After a reboot, the "shortcut is off" note on the home screen now clears as soon as the accessibility service starts, instead of staying until you leave home and come back.

### Install

Download `QSearchLauncher-0.5.2.apk` below and install it over 0.5.1. Your settings stay.

The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
