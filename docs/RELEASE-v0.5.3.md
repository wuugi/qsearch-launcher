The Fn key on the Unihertz Titan 2 now works in the search bar shortcut.

### Fix

- On the Titan 2, pressing Fn+Space while setting the shortcut saved only Fn, so pressing Fn alone opened the search bar. Fn now works as a modifier, like Ctrl or Alt: you can set Fn+Space, Fn+J and similar shortcuts, and pressing Fn alone does nothing.
- This applies to the shortcut on the home screen and to the shortcut that opens the search bar from other apps.
- If you set a shortcut on a Titan 2 with 0.5.2 and it shows only the Fn key, it is cleared when you update. Set it again from Settings.

### Install

Download `QSearchLauncher-0.5.3.apk` below and install it over 0.5.2. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
