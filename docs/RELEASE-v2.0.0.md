Notes, to-dos and replies from the search box.

### New

- **Notes and to-dos.** Type `!` and some text, then press Enter, to save a note. `_` saves a to-do. They are kept only on this phone.
  - `!` or `_` on its own lists what you saved right away. Keep typing to write a new one or to search the list.
  - Press Enter or tap a to-do to complete it. Press Enter on a note to open it, edit it in place, or copy it.
  - Delete with Shift+Backspace twice, or swipe a row to the right. After a swipe, tap "Undo" while it shows to bring the item back.
  - The prefix you typed turns bold and takes a colour, so you can see the command is on.
  - Settings → Search → Command prefixes turns `!` and `_` off. Saved items stay.
- **Reply from search** (off by default). Type `@` to list recent notifications you can reply to, such as KakaoTalk and Google Messages. Pick one, type, and press Enter. The reply goes to that app, the search box closes and the notification is cleared. If the notification is gone by then, you see an error and your text stays.
  - Turn it on in Settings → Search → Reply from search. It also needs notification access.
  - Replies are blocked while the screen is locked.
- **Backup** now includes notes, to-dos and the reply switch. Before a restore, the summary shows how many notes and to-dos the file holds, and warns you if restoring would clear your current ones.
- **Settings** shows the app version.
- **Motion.** Results come in faster, and command mode has its own motion when lists open, narrow and complete. With animations turned off in Android, everything appears at its final state.

### Permissions

No new permissions. Reply from search uses the notification access that unread dots already ask for.

- Notification text is read into memory only while the `@` list is open, and is cleared when you close search or leave the launcher. It is never stored, logged, backed up or sent.
- Notes and to-dos never leave the phone, except in a backup file you export yourself.

Details are in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).

Download `QSearchLauncher-2.0.0.apk` below and install it over 1.0.0. Your settings stay.
