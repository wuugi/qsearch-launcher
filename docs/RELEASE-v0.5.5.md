More room for widgets.

### Change

- Widgets now use all the space down to the top of the favorites. Before, an empty row was always kept below the widgets, so on a square 1440x1440 screen they got only about half the screen. To add a widget or open the app drawer while the widgets fill their space, long-press or swipe up on the empty edge of the favorites area.

### Install

Download `QSearchLauncher-0.5.5.apk` below and install it over 0.5.4. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
