### Fix

- On phones whose keyboard app stays active while you type on the hardware keyboard (like the Unihertz Titan 2), pressing Enter in search did nothing. You had to tap the result. Enter now opens the highlighted result again. The keypad Enter key works too.

### Install

Download `QSearchLauncher-0.5.8.apk` below and install it over 0.5.7. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
