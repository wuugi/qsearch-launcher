### Fixed

- **Prefix hint animation no longer stops abruptly.** The dim hint that fades in after `!`, `_` or `@` used to overshoot full brightness and then snap to a stop at the end of the fade. It now eases in smoothly to its final shade.

### Permissions

No changes since 2.1.0.

### Install

Download `QSearchLauncher-2.2.0.apk` below and install it over 2.1.0. Your settings stay.
