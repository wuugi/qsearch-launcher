A small follow-up to 0.5.5.

### Fix

- An empty strip now stays above the favorites. It is not drawn, so you only see your wallpaper there. When the widgets fill their space and all eight favorites are taken, you can still long-press it to add a widget, or swipe up from it to open the app drawer. Before, only the narrow side edges were left, and they overlap the system back gesture.

### Install

Download `QSearchLauncher-0.5.6.apk` below and install it over 0.5.5. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
