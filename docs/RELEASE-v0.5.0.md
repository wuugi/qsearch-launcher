## 한국어

첫 공개 릴리스입니다. 모든 기능을 잠금 없이 무료로 쓸 수 있습니다.

검색
- 단축키로 여는 검색창: 앱 이름(한글 초성 포함)과 자주 여는 앱 순위, 계산, 단위 변환
- 다른 앱 위에서도 단축키로 열기(접근성 서비스), 빠른 설정 타일
- 환율 변환: 원·달러·엔과 통화 12개, 기준 통화 고르기(기본 꺼짐, 켜면 하루 한 번 환율표만 받음)
- 문자 본문 검색(선택). Google과 Play 스토어 검색 행, 검색창 위치(위/아래)

홈
- 4열 즐겨찾기, 위젯(추가, 높이 조절, 끌어서 순서 바꾸기)과 위젯 스택, 읽지 않은 알림 점
- 머티리얼, 글래스, 클래식 쿼티 테마와 아이콘 팩
- 배경화면만 보기, 두 번 탭으로 화면 잠금, 두 손가락으로 알림창 내리기
- 설정 백업과 복원
- 초성 막대와 길게 누르기 메뉴가 있는 앱 서랍, 숨긴 앱. 화면 문구는 한국어, 영어, 일본어

앱 전체 소스는 공개하지 않고, 문자·알림·키 입력·네트워크·백업을 다루는 코드만 이 저장소에 공개했습니다.
개발자는 사용자 데이터를 전혀 수집하지 않습니다. 권한 목록은 [docs/PRIVACY.md](PRIVACY.md)에 있습니다.

설치: 아래 `QSearchLauncher-0.5.0.apk`를 받아 설치하고, 홈 버튼을 눌러 Q Search를 기본 홈으로 고릅니다.
"기기 보호를 위해 앱 차단됨"이 뜨면 README의 설치 절을 봐 주세요.

## English

The first public release. Every feature is free, with nothing locked.

Search
- A search box opened with a shortcut: app names (Korean initial consonants included) with frequency ranking, math, unit conversion
- Open it with the shortcut over other apps too (accessibility service), or from a Quick Settings tile
- Currency conversion: KRW, USD, JPY and 12 more, with a base currency you choose (off by default; when on, one rate table a day)
- Optional SMS body search. Google and Play Store rows, search box at the top or bottom

Home
- 4-column favorites, widgets (add, resize, drag to reorder) and widget stacks, unread notification dots
- Material, Glass and Classic QWERTY themes, icon packs
- Wallpaper only, double-tap to lock the screen, two-finger swipe down for the notification shade
- Settings backup and restore
- App drawer with an index bar and a long-press menu, hidden apps. The UI is in Korean, English or Japanese

The app's full source is not published; the code that handles SMS, notifications, key presses, the network and backups is published in this repository.
The developer receives none of your data. The permission list is in [docs/PRIVACY.md](PRIVACY.md) (Korean).

Install: download `QSearchLauncher-0.5.0.apk` below, install it, then press Home and pick Q Search as the default home app.
If you see "App blocked to protect your device", see the Install section of the README.
