A small fix for the Glass theme.

### Fix

- In the light Glass theme, long-press menus (on the home screen, in the app drawer and in search results) showed a smudged rectangle behind the menu text. The menu's shadow was showing through the see-through panel. Menus in see-through themes no longer draw a shadow.

### Install

Download `QSearchLauncher-0.5.4.apk` below and install it over 0.5.3. Your settings stay.

This release adds no new permissions. The permission list is in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).
