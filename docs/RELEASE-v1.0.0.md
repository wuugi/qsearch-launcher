Contact search in the search box.

### New

- Type part of a name, its Korean initial consonants (for example `ㅎㄱㄷ`), or three or more digits of a phone number, and up to five people from your address book show up below the app results. Hyphens and spaces don't matter, and a number saved as `+82 10 1234 5678` is found when you type `010…`.
- Each person gets one row with one phone number: the number you searched for, or their main number when you searched by name.
- Tap a row or press Enter to open that person in your contacts app. Q Search never places a call.
- Only people your contacts app shows are searched. "Other contacts" and hidden groups are left out.
- Contact search turns off in Settings → Search → Contacts.

### Permissions

This release adds no new permissions. Contact search uses the "Read contacts" permission that SMS search already asked for to show sender names.

- If you already allowed it, contact results appear right after the update. Turn off Settings → Search → Contacts if you don't want them.
- If you haven't, the search box shows a "Turn on contact search" row when you type. Choose it to see the system permission dialog. If you deny, the row goes away and doesn't come back; you can still allow it later in Settings → Permissions.

Contacts are read only while you search and are never stored or sent. Details are in [docs/PRIVACY.md](https://github.com/wuugi/qsearch-launcher/blob/main/docs/PRIVACY.md) (Korean).

### Install

Download `QSearchLauncher-1.0.0.apk` below and install it over 0.6.1. Your settings stay.
