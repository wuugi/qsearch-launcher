A hint for each command prefix.

### New

- **Prefix hints.** Type `!` or `_` and pause for half a second, and a dim line fades in after the prefix, letter by letter: "Search your notes, or add a new one." or "Search your to-dos, or add a new one." With `@`, "Pick a notification to reply to it." shows after 0.3 seconds. Type the next letter and the hint goes away. The hint follows the phone's language (English, Korean, Japanese).

### Permissions

No changes since 2.0.0.

### Install

Download `QSearchLauncher-2.1.0.apk` below and install it over 2.0.0. Your settings stay.
